# Settings calibration ornament

This is the single image asset from the 2026-09-18 Settings concept: the small brass observatory calibration-instrument vignette beside the Settings title.

`settings-calibration-instrument.png` is a newly generated, concept-inspired RGBA master created on 2026-09-22 with built-in ImageGen using the Settings concept as a visual reference. It is not an extracted original or an exact tracing. The full Settings page and its icon rows are outside this asset delivery.

The master is 1536×1024 with alpha transparency. The visible instrument occupies the central area; inspect its visible bounds before making the production derivative. Intended use is a quiet ornament at roughly 90–120 CSS pixels wide on mobile. Keep it secondary to the title, preserve transparent edges, and test it on the indigo Observatory background and in both themes. Do not use it as a control, status indicator, or semantic account icon.

No application files were changed and the asset has not been integrated or deployed.
