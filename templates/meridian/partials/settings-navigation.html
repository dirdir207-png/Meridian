{# Settings hub — the 09-18 concept's grouped directory. Governing authority: design/observatory-extension-2026-09-18/concepts/settings.png. The concept is a hub of grouped rows leading to detail surfaces, with three parchment group banners (CONNECTIONS / VIRGIL & AUTHORITY / PREFERENCES) and nine rows, each an icon medallion, a title, a subtitle and a chevron. Three things this file is deliberate about: 1. ONE ROW PER CONCEPT ROW, pointing at the section that serves it. The nine concept rows resolve to five real routes (several rows share a surface -- both Connections rows open the connections ledger, which already groups them by kind). Every href is a route that already existed; this slice adds no route. 2. A ROW WITH NO READ MODEL IS NOT A LINK. "Memory & privacy", "Briefings & quiet hours" and "Appearance" have no route, no partial and no read model today. The build handoff is explicit that unavailable features must "say unavailable/planned, not show working switches", and a row that opens an empty page would claim a surface that does not exist. They render as non-interactive rows that state "Planned". Wiring one is a later slice with its own read model; this file grants no capability. 3. The group banners reuse the parchment nine-slice already serving `.obs-evidence-ticket`, and the row glyphs are the SHIPPED KIT's own SVGs referenced as CSS masks (the established pattern), so no new artwork is invented and the assets stay single-sourced under static/img where ASSET_MANIFEST is their authority. #}
