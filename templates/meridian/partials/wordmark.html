{# Shared Observatory wordmark. The concept draws an ORANGE STAR above the FIRST i of "Meridian" (settings.png and timeline.png both), with the second i keeping an ordinary dot. The shipped mark had it inverted -- an apricot circular DOT on a dotless SECOND i -- so the mark was on the wrong letter and the wrong shape. The dotless letter (U+0131) is therefore the first i, and the star is a CSS pseudo-element that contributes no text to the accessibility tree, so the visible letters still read "Meridian". Callers own the accessible name: the rail and the Settings header supply aria-label on the surrounding link, and the main mobile header supplies a visually-hidden "Meridian" text alternative. #} Merıdian
